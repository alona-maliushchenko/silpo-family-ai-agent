# Silpo Family AI Agent

AI agent for family meal planning and smart grocery shopping using the official Silpo MCP.

## Project Goal

The agent helps families:

- plan meals for several days;
- create a grocery shopping list;
- consider the number of family members;
- use products available in Silpo;
- optimize the shopping process;
- interact with the user through natural language.

## Tech Stack

- TypeScript
- Node.js
- AI Agent
- MCP
- Silpo MCP
- Git
- GitHub
