# 🛒 Silpo Family AI Agent

AI-агент для розумного планування сімейних покупок та харчування з використанням **MCP Сільпо**.

## 💡 About the Project

**Silpo Family AI Agent** допомагає сім'ї планувати харчування та покупки відповідно до кількості людей, бюджету, побажань і доступних продуктів.

AI-агент може аналізувати запит користувача, знаходити необхідні товари через **Silpo MCP**, порівнювати варіанти та формувати оптимальний список покупок.

### Приклад запиту

> «Склади меню на 3 дні для сім'ї з 4 людей з бюджетом до 1500 грн.»

Агент:

1. 🍽️ Формує меню.
2. 🛒 Визначає необхідні продукти.
3. 🔎 Отримує інформацію про товари через MCP Сільпо.
4. 💰 Розраховує орієнтовну вартість.
5. 🔄 Пропонує альтернативи, якщо це необхідно.
6. 📋 Формує готовий список покупок.

## 🎯 Hackathon Goal

The goal of the project is to demonstrate how an AI agent can use real-world tools and grocery data to solve everyday family planning tasks.

The project focuses on combining **AI + MCP + grocery data + family-oriented planning** into a practical assistant.
